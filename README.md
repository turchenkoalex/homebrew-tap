# turchenkoalex/tap

Homebrew formulae for [martty](https://github.com/turchenkoalex/martty), a Markdown
viewer for Ghostty.

```sh
brew install turchenkoalex/tap/martty
```

The formula installs the prebuilt binaries from martty's releases: macOS on Apple silicon,
Linux on x86_64 and arm64. martty's release workflow updates it on every release.
